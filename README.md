# woyean5.github.io

Conner (양건휘)의 개인 포트폴리오 사이트예요. AI 학과 프로젝트, 학생회 홍보 활동, 유튜브 영상 작업, 기술 스택을 한 페이지에 모았습니다.

## 특징

- 단일 파일(`index.html`)로 구성된 정적 사이트, 별도 빌드 없이 GitHub Pages에서 바로 열립니다.
- Tailwind CSS(CDN)와 인라인 SVG 아이콘을 사용합니다.
- 한국어(기본), 영어, 일본어를 지원합니다.
- 스크롤 연동 애니메이션과 반응형 레이아웃을 적용했습니다.

## 구성

- Hero: 소개와 소셜 링크 (GitHub, YouTube, Instagram, Spotify)
- Projects: 프로젝트 카드, 가로 스크롤 방식
- About: 경험과 관심사
- Videos: 유튜브 영상 임베드
- Tech Stack: 사용 언어와 도구
- Contact: 이메일 복사와 연락 링크

## 배포

`main` 브랜치에 `index.html`을 커밋하면 GitHub Pages가 자동으로 배포합니다.

https://woyean5.github.io
